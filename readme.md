## Библиотека симуляции очереди клиентов и их обработки
Поддерживает следующий функционал:  
- Симуляция вероятности распределения.
- Удобная модификация распределений.
- Удобная модификация работы симуляции.
\
### Компиляция
Присутствует Makefile.  
Также существует возможность установки флага DEBUG.  
  Установка флага DEBUG осуществляется в Makefile, раскомментированием  
  соответствующей строчки.  
\
На текущий момент поставляется с 1 из 4 примерами использования.
